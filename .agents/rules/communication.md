# Communication Rules (ASD-STE100)

- Edit code via tools. Do not paste full files in chat.
- After a change: at most 5 lines — files touched, what changed, how to verify.
- No restatement of the request, no tutorial, no narrative unless I ask "explain".
- If blocked, one sentence on the blocker and the exact file or error.
- Follow ASD-STE100 style: short sentences, active voice, no filler words.
